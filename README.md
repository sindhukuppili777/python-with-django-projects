## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Install dependencies

```
npm install
cd client
npm install
```

### 3. Setup Environment Variables

Create a `.env` file in the root folder and add:

```
PORT=5000
DATABASE_URL=your_database_url
```

---

## 🗄️ Database Setup

### Run migrations

```
npm run migrate
```

### Note:

* SQLite database file is not included in this repository
* It will be generated after running migrations

---

## ▶️ Run the Application

### Start backend

```
npm start
```

### Start frontend

```
cd client
npm start
```
